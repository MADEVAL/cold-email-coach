# Cold Email Coach

[skills.sh profile](https://www.skills.sh/madeval) - этот скилл ещё не в каталоге.

**Пишите письмо, на которое человек реально ответит.**

Большинство холодных писем проваливаются по скучной причине: они про отправителя. Абзац истории компании, список фич, просьба о демо и через три дня - "просто напоминаю". Получателю не за что зацепиться и неудобно ответить.

Это скилл для AI-агентов, который это исправляет. Дайте ему, кому пишете, что продаёте и какую проблему решаете. Он напишет два-три коротких письма, оценит их по чек-листу из 11 пунктов и вырежет всё, что ещё пахнет рассылкой.

Правила взяты у двух людей, которые думали о холодных письмах больше многих: Josh Braun и Will Allred. Принципы изложены своими словами. Без цитат, без имён ради веса и без аффилиации.

## Что делает

| Режим | Вход | Выход |
|---|---|---|
| **WRITE** | Получатель и оффер | 2-3 коротких письма с темой и числом слов |
| **REVIEW** | Готовое письмо | Чек-лист из 11 пунктов, оценка из 11, до 3 правок |
| **REWRITE** | Готовое письмо | Короткий разбор, оценка и исправленная версия |

Ещё он делает follow-up, темы писем и разбирается со случаем, когда факта для персонализации нет. Тогда он ставит плейсхолдер, а не выдумывает комплимент.

## 11 проверок

Каждое письмо оценивается по одним и тем же пунктам:

1. 50-125 слов.
2. Первая строка про получателя.
3. Без питча и списка фич.
4. Конкретная проблема или наблюдение, а не "мы лучшие".
5. Ровно один CTA, на который легко ответить.
6. "You" встречается чаще, чем "I/we".
7. Простые слова, без жаргона.
8. Короткая нейтральная тема письма.
9. Без шаблонных зачинов и клише.
10. Без фальшивой срочности и обещанных результатов.
11. Читается вслух без желания закрыть ноутбук.

Оценка - это диагноз, а не гарантия. Скилл так и говорит, и это правда.

## Установка

```bash
git clone https://github.com/MADEVAL/cold-email-coach.git
cd cold-email-coach
python install.py --target all
```

Скилл копируется в:

- **Claude Code:** `~/.claude/skills/cold-email-coach`
- **OpenCode:** `~/.config/opencode/skills/cold-email-coach`
- **Portable:** `~/.agents/skills/cold-email-coach`

Полезные флаги:

```bash
python install.py --list     # где установлено
python install.py --check    # сравнить установленные копии с репозиторием
python install.py --target project   # установить в ./.opencode/skills
```

Зависимостей нет. Python 3.9+ нужен только для опционального линтера и установщика.

## Использование

Спрашивайте обычным языком:

- "Напиши холодное письмо Head of Support в SaaS на 200 человек. Мы продаём маршрутизацию тикетов. На их странице поддержки обещан первый ответ за 12 часов."
- "Разбери это холодное письмо. Не переписывай."
- "Перепиши. Тут 240 слов и просьба о демо."
- "Три follow-up. На первое письмо не ответили."
- "Пять тем письма про отвал на онбординге."
- "Напиши на немецком. Получатель в Берлине."

Режим скилл выбирает сам: письмо без инструкций - **REWRITE**, без письма - **WRITE**, "оцени" - **REVIEW**.

## Как выглядит результат

```text
Subject: week one

Dana - your post about 40% of new accounts never finishing setup stayed with me.
That number usually lives in a spreadsheet, and someone ends up chasing each
account by hand.

We make a small checklist tool for CS teams. It shows where each account gets
stuck, so nobody has to guess.

Is that still a problem for you, or is setup under control?

Yevhen, Founder at Relay

Words: 67
```

Разбор выглядит так:

```text
1. Length - FAIL (213 words)
2. First line - FAIL ("I hope this email finds you well" is about the sender)
...
Score: 0/11

Top fixes
1. Replace the first two paragraphs with one observation about the recipient.
2. Cut from 213 to about 70 words.
3. Remove the demo, the calendar link, and the reply request. Keep one question.
```

## Опциональный линтер

Для быстрой механической проверки:

```bash
python scripts/email_lint.py draft.txt
cat draft.txt | python scripts/email_lint.py
```

Он показывает число слов, уровень читаемости, соотношение you/I, количество вопросов и просьб, длину темы, клише, слова срочности, CAPS, восклицательные знаки, ссылки и плейсхолдеры. Возвращает ненулевой код, когда не проходит жёсткая проверка.

Он не оценивает релевантность, персонализацию и голос. Это по-прежнему работа модели и ваша.

## Решения по дизайну

- **Коротко важнее, чем остроумно.** 50-125 слов. Если письмо нужно скроллить на телефоне, оно не готово.
- **Одна просьба.** Второй CTA - не запасной план. Это причина не делать ничего.
- **Никаких выдуманных фактов.** Ни фальшивой персонализации, ни воображаемых клиентов, ни придуманных метрик. Плейсхолдер честен, его заполнят.
- **Никакой фальшивой срочности.** Настоящие дедлайны допустимы. Искусственные стоят доверия.
- **Язык - язык получателя.** Письмо пишется на его языке, а не переводится слово в слово с английского.
- **Только plain text.** Без HTML, картинок, пикселей отслеживания и баннерных подписей.

## Ограничения

- Это не CRM, не секвенсор и не инструмент доставляемости.
- Он не может проверить, что ваш кейс настоящий. Это ваша работа.
- Чек-лист - диагностика. Письмо на 10/11 всё равно может быть нерелевантным.
- Ни один инструмент не может обещать ответы. Кто обещает - продаёт что-то другое.
