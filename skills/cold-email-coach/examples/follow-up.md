# Example: follow-ups

> All names and companies are fictional.

## Context

Same brief as `examples/write.md`: Dana Ruiz at Northwind, Relay onboarding checklist, one reply requested. Dana did not answer the first email. The sequence is three touches, then stop.

## Touch 1 - original

**Subject:** week one

Dana - your post about 40% of new accounts never finishing setup stayed with me. That number usually lives in a spreadsheet, and someone ends up chasing each account by hand.

We make a small checklist tool for CS teams. It shows where each account gets stuck, so nobody has to guess.

Is that still a problem for you, or is setup under control?

Yevhen, Founder at Relay

**Words:** 67

## Touch 2 - new angle, 4 days later

**Subject:** day three vs day thirty

Dana - one more angle on setup drop-off, in case it is still open. Most teams find stuck accounts in a weekly review, which means the customer has already been quiet for a week.

A short daily list turns that review from an autopsy into a check-in.

Is that already how Northwind works?

Yevhen, Founder at Relay

**Words:** 56

## Touch 3 - clean exit, 6 days later

**Subject:** closing the loop

Dana - last note from me. If setup drop-off becomes a priority, reply and I'll pick it up.

If not, no hard feelings. I'll stay out of your inbox.

Yevhen, Founder at Relay

**Words:** 32

Touch 3 is below the 50-word target on purpose. Exit notes can be short because there is no argument left to make. The rule is "no padding", not "must hit 50".

## Why this sequence works

- Each touch adds something new. None of them says "just following up".
- Touch 2 reframes the problem instead of repeating it.
- Touch 3 gives a real exit. The recipient can ignore it without guilt, and the sender can stop.
- No calendar link, no case study, no second ask.
- If there is no reply after touch 3, the sequence ends.
