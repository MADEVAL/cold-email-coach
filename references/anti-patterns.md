# Anti-patterns

The fastest way to sound like a campaign is to use the phrases every campaign uses. Below are the usual suspects and what to write instead.

## Clichés

| Cliché | Why it fails | Write instead |
|---|---|---|
| "Hope this email finds you well" | About the sender's manners, not the recipient | Start with the observation |
| "Hope you're doing well" | Same, and it delays the point | Cut it |
| "I hope I'm not bothering you" | Apologizes for existing | Cut it |
| "I know you're busy" | Everyone knows; saying it wastes a line | Cut it |
| "I wanted to reach out because..." | Announces the email instead of making a point | Make the point |
| "I'm reaching out to..." | Same | Same |
| "My name is X and I work at Y" | The signature already says this | Introduce context, not identity |
| "We are a leading provider of..." | Unverifiable and self-focused | One sentence about the problem you solve |
| "We help companies like yours..." | "Companies like yours" is not a person | Name the specific team and problem |
| "Just following up" | Adds no information | Add a new angle |
| "Circling back" | Same, with extra jargon | Add a new angle |
| "Bumping this" | Guilt without value | Add a new angle or stop |
| "Touching base" | Says nothing | Say the thing |
| "Quick question" | Usually not quick, and overused | Ask the actual question |
| "Quick call" | Assumes the recipient wants a call | Ask if the topic is relevant |
| "Pick your brain" | Vague and one-sided | Ask a specific question |
| "At your earliest convenience" | Corporate filler | "When you have a minute" |
| "Please don't hesitate to..." | Filler | Cut it |
| "I'd love to..." | About the sender's feelings | State the ask plainly |
| "Would you be open to..." | Fine once, cliché when stacked with another ask | One clear question |
| "As per my last email" | Passive-aggressive | Add new information |
| "Per my last email" | Same | Same |
| "Let's take this offline" | Jargon | "Want to talk it through?" |
| "Move the needle" | Business jargon | Say the actual change |
| "Low-hanging fruit" | Jargon | "The easiest fix" |
| "Game changer" | Hype | Describe the change |
| "Revolutionary" | Hype | Describe the change |
| "Cutting-edge" | Hype | Cut it |
| "Best-in-class" | Unverifiable | Use a real, specific proof point |
| "World-class" | Unverifiable | Cut it |
| "Seamless" | Meaningless | Describe the experience |
| "Robust" | Meaningless | Describe what it handles |
| "Synergy" | Jargon | "Working together" |
| "Leverage" | Jargon | "Use" |
| "Utilize" | Jargon | "Use" |
| "Facilitate" | Jargon | "Help" |
| "Optimize" | Jargon | "Improve" |
| "Streamline" | Jargon | "Simplify" |
| "End-to-end" | Jargon | "One place for X" |
| "Solution" | Says nothing | "Tool", "service", "checklist" |
| "Pain points" | Vendor language | "Problems" |
| "Value-add" | Jargon | "Useful" |
| "ROI" in the first email | Premature | Save it for the conversation |
| "No-brainer" | Pressure disguised as arithmetic | Let them decide |
| "Last chance" | Fake urgency | State a real deadline or nothing |
| "Act now" | Fake urgency | Same |
| "Limited spots" | Fake scarcity unless true | State the real limit |
| "Guaranteed results" | A promise you cannot keep | Describe what you do |
| "10x your pipeline" | Exaggeration | A real, specific outcome |
| "This will change everything" | Hype | Describe one concrete change |

## Structural mistakes

### The feature dump

A paragraph of capabilities. The recipient has not agreed there is a problem yet, so features have nothing to attach to.

**Fix:** one problem sentence, one context sentence, one question.

### Two CTAs

"Book a call or reply with your thoughts." Two doors means no door.

**Fix:** pick the lower-cost ask. Usually the question.

### The resume email

The sender's credentials, clients, awards, and years of experience before any relevance.

**Fix:** remove the biography. Keep one proof point only if it directly supports the problem.

### The fake personalization

"Loved your recent post!" with no post, or a compliment that could apply to anyone.

**Fix:** be specific or use a placeholder. Generic praise is worse than none.

### The humble-brag case study

A long story about a client that ends with a metric and a request for time.

**Fix:** one line, no adjectives, and only if the case is real and relevant.

### The guilt follow-up

"Just checking in", "Did you see my last email?", "I'll assume you're not interested."

**Fix:** add a new angle, or stop.

### The calendar link

A booking link in the first email pushes the recipient to make a decision before they have a reason.

**Fix:** ask a question first. Share the link after they reply.

### The wall of text

No white space, long paragraphs, multiple ideas.

**Fix:** four short paragraphs at most. One idea each.

### The clever subject line

A joke, a pun, or a fake "Re:" that has nothing to do with the email.

**Fix:** a neutral phrase from the recipient's world.

### The hidden ask

The email ends with "Thanks!" and no question. The recipient has nothing to do, so they do nothing.

**Fix:** one clear, low-cost question.

### The premature demo

Asking for a meeting before establishing relevance.

**Fix:** earn the reply first. The meeting is the second conversation.

## A final test

Read the email aloud. If any sentence sounds like it belongs in a brochure, a legal disclaimer, or a LinkedIn announcement, rewrite it. If the email could be sent to a hundred people without changing a word, it is not personalized. If the only thing the recipient can do is feel impressed, it is not a cold email.
